# Name and Mark Usage Policy

## Package name

`misskey_dart_api` is a descriptive package name. It indicates that the package
is a Dart API client for Misskey; it does not claim ownership of the Misskey
name or project.

## Misskey marks

"Misskey" and the Misskey logo are marks of the Misskey project and its
contributors. This package is not affiliated with, endorsed by, or sponsored by
the Misskey project. Use of the name is descriptive only.

## No trademark license

The BSD-3-Clause license applies to code. It does not grant a trademark license
for "Misskey", "misskey_dart_api", or any third-party marks.

## Permitted use

- Factual references such as "a Dart API client for Misskey".
- Articles, tutorials, and talks about the package, provided they do not imply
  official endorsement by Misskey or the package maintainer.
- Retaining copyright and license notices in forks.

## Prohibited use

- Implying that your fork or product is official Misskey, the Misskey project,
  or `misskey_dart_api`.
- Using Misskey marks in a way that is likely to confuse source or sponsorship.
- Registering trademarks, domains, or package names identical or confusingly
  similar to Misskey marks.

## Contact

For trademark questions, contact the maintainer through a GitHub Issue titled
"Trademark". For sensitive matters, use Security Advisories.
