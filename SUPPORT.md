# Support

## Getting help

- **Bugs**: use the GitHub Issue Bug report template.
- **Feature requests**: use the Feature request template.
- **Security issues**: do not open a public issue; use
  [GitHub Security Advisories](https://github.com/CyaniAgent/misskey_dart_api/security/advisories/new).
- **Usage questions**: search existing issues first. If still unresolved, open
  an issue with the package version, Dart/Flutter version, reproduction steps,
  and redacted logs.

## Supported scope

- `misskey_dart_api` package code, tests, and documentation.
- Misskey API request construction and error handling when reproducible.
- Build/analyzer issues on the latest published version.

## Out of scope

- Misskey instance servers, accounts, moderation, or data; contact the instance
  administrator.
- Apps that use this package and their own data handling.
- Third-party packages, operating systems, or app stores.
- Custom development or commercial SLAs.

## Response time

This is a personal open-source project without guaranteed response times or a
commercial SLA. The maintainer will make a best effort; priority depends on
impact, reproducibility, and availability.

## Before asking

1. Search open and closed issues.
2. Confirm you are using the latest published version or `main`.
3. Remove tokens, cookies, private messages, server addresses, and other
   sensitive data.
4. Provide minimal reproduction steps and relevant log excerpts.

## Commercial support

For commercial support, customization, or licensing questions, contact the
maintainer through a GitHub Issue titled "Commercial inquiry". Acceptance is at
the maintainer's discretion.
